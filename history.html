版本历史

1.2（build 2）

新功能

  • 跨谱表琶音（重点）：钢琴、竖琴这类"上下两行"的乐器，两行共用一个琶音的写法， 现在显示成一条贯穿两行的波浪线（原来上下各画半段、互不相连）； 向下的跨谱表琶音、同一拍各自独立的两个琶音、以及"不要琶音"的括号也一并修好
  • 打开与互转乐谱文件：支持打开 .mscz / .mscx 乐谱文件，并可在两种格式之间互相转换（压缩包 ↔ 纯文本）
  • 琶音可以滚奏，速度也能调：跨谱表琶音现在默认按滚奏演奏 —— 从最低音依次奏到最高音， 起音有先后、收停同时（钢琴卷帘上是一个直角梯形，任何音都不会拖进下一小节）； 设置 ▸ 琶音里可以关掉，速度分慢 / 中 / 快 / 自定义四档， 自定义可填每音间隔 0.01–2.0 拍。八音大和弦不再挤成"四个在滚 + 一个和弦"； 钢琴卷帘里看到的阶梯与听到的完全一致
  • 调性看得见：主界面标题下新增「调性 C 大调」一行；谱中换过调号时注明「（共 N 处调号）」； 练习曲现在写明调式，小调不再显示成「C 大调 / a 小调（调式未标注）」
  • 速度记号面板：一份谱有多条速度记号时，速度行右侧出现入口 —— 列出全部记号 （小节 / 声部 / BPM / 基准），可逐条滑动改、按比例 50%–200% 应用到全部、统一设为 N BPM、删除单条
  • 跨谱表琶音示例谱：内置范例新增《跨谱表琶音》——十二小节、单声部两谱表，像电子琴那样 中途换音色：竖琴（1–4 小节）→ 钢琴（5–8 小节，带延音踏板）→ 钢片琴（9–12 小节）； 每次换音色在谱面写一行音色文字，C 大调 I–vi–ii–V 的和声走句配 p / mf / f 力度， 琶音上行与下行混排，起句小节末拍加两个八分音符带动进行，收尾和弦向下滚奏并带延长记号。 选中任意音后可在「音符详情 ▸ 音乐课堂」逐条看讲解
  • 音乐课堂：「琶音 / 滑音」分类下新增「跨谱表琶音」与「非琶音括号」两条
  • 音乐课堂补全「弯音」：新增「弯音（滑入 / 滑出 / 推弦）」一类 —— 舀音、轻落音、坠音、 上划出与推弦（含先推后弹 / 推后放回 / 摇把）逐条讲清方向与听感； 并补齐此前没讲的记号：颤音前置音与延长线、装饰音的专属形式（海顿 / 颤波 / Schleifer…）、 拨奏 / 闷音 / 空弦 / 响指拨弦 / 点弦 / 脚跟脚尖、人工泛音与泛音基础音、 先渐强后渐弱（梭形）与文字式渐强渐弱、选择延音踏板与半踏板、提示音（不发声）与鼓音

排版与记号

  • 琶音线改到符头左侧（原来压在符头上，全音符和弦时几乎看不清）
  • 修掉"同一行里多个小节都有琶音时，只有第一条画得出来"的问题
  • 谱表放大到 100% 以上时，横向间距跟着放大（以前只放大字形，符头会与临时记号、 同和弦的音互相压住；100% 时的版面与 1.1 逐像素一致）
  • 小节开头的倚音放不下时，让位改为向前渐消，末拍不再被顶出小节线
  • 多声部休止符水平避让：同拍上别的声部有实音时，休止符不再压在人家符头上

播放与弯音

  • 所有弯音类记号都会发声：坠音、舀音、轻落音、上划出 / 下滑出 （<falloff/> / <scoop/> / <plop/> / <doit/> 以及 <slide> 写法）与吉他推弦 （含先推后弹、推后放回）都按谱面演奏；落在延音线收束端的记号同样生效 —— 此前《自由》m63 / m65 / m67 三处坠音谱面上有、播放里一声不响
  • 打击乐混排：5 线鼓谱混在旋律声部里时，鼓音单独走鼓通道发声（设置里可关）， 不再被当成旋律音弹出来；单线鼓谱以外的鼓谱按实际线数绘制
  • 播放口径按实测校准：倚音、装饰音、滑音、琶音与打击乐的起音位置、 时值与通道逐项对拍（同一份谱导出的 MIDI 事件位置与数量符合预期）

兼容与导出

  • 导入版式逐项校准：多谱表各自的中途换谱号、八度记号按谱表跨小节持续、 符杠切组（<beam> 组结束后的音不再被卷进上一组）
  • 八度记号跨行：行末不再画直角钩、续行重新写出「8」，只在整段真正的终点收口
  • 导出端改用规范元素（颤音修饰、微音提示），避免非标准写法在部分制谱软件中引发异常

问题修复

  • 导入 .mscz 更稳：打击乐段的谱号正确画成双竖线（此前误画成高音谱号）； 换回有调号乐器时补画调号；原生弦位记录不再显示成符头旁的小数字
  • 八度记号往返保真：导出 .mscz 后再打开，八度区间覆盖的音符范围不变
  • 重新打开与乐谱库：上次打开的是 .mscz 时不再报文件类型错误； 从乐谱库点选乐谱后直接显示谱面（此前仍停留在文件名列表）

1.1（首次更新 · build 1）

新功能

  • 简谱视图（实验）：乐谱可一键切换成简谱（数字谱）——默认只记旋律， 也可切换为和弦叠排；与五线谱共用同一份乐谱，切换不会改动原谱
  • 覆盖谱练习（实验）：四份单一主题短谱，专练反复与跳转 —— 反复与结尾 / 小节·拍重复 / D.S.·Coda / D.C.·Fine；并修掉 To Coda 首遍误跳
  • 乐谱库：打开过的乐谱自动入库，可收藏、重命名、删除
  • 练习扩充：新增音程训练 / 节奏型训练 / 和弦进行 / 视唱四类；短琶音按八度与 方向展开，改用考级通用的转位滑窗音型（原位 → 第一转位 → 第二转位 …）
  • 设置页：新增翻页方式（滑动 / 蓝牙踏板·键盘 / 半页）、Pencil 标注层、 蓝牙 MIDI 输出、链接与致谢；「关于」可直接查看版本号与 build 号
  • 快捷指令：支持用快捷指令 / Siri 打开最近乐谱（英文机上不再显示中文）
  • 改谱更安全：转调、连谱号等改动加二次确认

播放

  • 修掉「暂停后按继续会从头开始」；换谱后「继续播放」不再接着放旧谱
  • 播放光标改用单一时间轴：经过休止符与同音连线也按记谱位置推进
  • 速度记号按谱面单位播放与显示
  • iPhone 上翻到非最后一行时，谱面与光标不再上下反复跳动

排版与记号

  • 符杠：不再压住符头，也不再出现「第二道符杠没连到符干」；连谱组按 2 个 八度跨度上限断开，符干不再互相交叉
  • 换行与间距：一小节一行放不下时改为在小节内换行排到下一行（密集小节不再 挤成一团）；相邻音符按墨迹最小净空排布，符头不再互相压住；只是轻微超宽的小节 仍按压缩处理，不会白占一行
  • 谱号与拍号让位：中途换谱号、换拍号都按记号实际占位留出空间，不再压到音符； 并修掉真实乐谱里「谱号全乱」的回归
  • 记号位置：力度记号与渐强/渐弱楔形线移到谱表下方且跨度完整；八度记号移出 谱表、起止对齐；速度记号的音符时值字形与文字对齐；Segno / Coda 画在小节开头， Fine / To Coda / D.C. / D.S. 画在小节末尾；渐强/渐弱方向不再写反； 颤音 / 波音 / 回音与重音记号（^）固定在谱表上方
  • 画错的记号：修掉一批（Segno / D.S. / D.C. 画成了别的记号、速度记号的 音符时值、踏板释放记号、跳音与保持音图标互换、琶音波浪线、低音谱号的 15mb / 8va 等）
  • 波音与装饰音：字形已修正统一；详情面板的中文标签与字形、说明一致； 颤音 / 回音 / 逆回音 / 上·下波音的术语统一

记谱与 MusicXML

  • 多声部小节里某个声部时值不足拍号时，补出的休止符不再丢附点
  • 导入的 MusicXML 若没有时值标记，按实际时值推定（播放判断更准）
  • 每个声部都填满本小节（不再「总时长对不上拍号」）
  • 末小节那条「很长的黑线」查清是多小节休止的横杠画得不成形，已改为规范画法
  • 导出的 MusicXML 不再有格式违规（此前 86 处，已全部修正）
  • 新增罗马数字和弦与转位（含上/下标数字）的解析、显示与导出
  • 补齐隐藏音符、其它力度记号、连音比率、开弦记号等写法；跨小节渐强不再丢失终点
  • 对新版制谱软件导出的乐谱兼容更好

示例谱

  • 随包《示例进行曲》补上跳音、重音、保持音、连音线、同音连线、波音、三连音、 渐强与延长记号，打开就能在「音符详情 → 音乐课堂」里逐条看到讲解

体积与性能

  • 音色库改为压缩 .sf3（约 13.9 MB，首次启动在本地解码），随包体积大幅下降
  • 播放设置不再触发全谱重排；音乐会音高与钢琴卷帘加上缓存，光标跟随更省电

术语与文案

  • 按通行制谱术语统一（「和弦记号」等）；「覆盖谱」取代旧称；补齐英文文案
  • 随缘打赏：支持页面（设置 → 链接与致谢可达）留有开发者邮箱，完全自愿；应用内无任何支付
  • 简谱、覆盖谱标注为实验功能
