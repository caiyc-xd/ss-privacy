版本历史

1.1（首次更新 · build 1）

  • 播放：修掉「暂停后按继续会从头开始」；换谱后「继续播放」不再接着放旧谱； 播放光标改用单一时间轴，经过休止符与同音连线时也按记谱位置推进；速度记号按谱面单位播放与显示
  • 播放跟随：iPhone 上翻到非最后一行时，谱面与光标不再上下反复跳动
  • 符杠：符杠不再压住符头，也不再出现「第二道符杠没连到符干」；连谱组按 2 个八度跨度上限断开， 符干不再互相交叉
  • 换行与间距：一小节一行放不下时改为在小节内换行排到下一行（密集小节不再挤成一团）； 相邻音符按墨迹最小净空排布，符头不再互相压住；只是轻微超宽的小节仍按压缩处理，不会白占一行
  • 谱号与拍号让位：中途换谱号、换拍号都按实测字形宽为其留出位置，不再压到音符上； 并修掉真实乐谱里「谱号全乱」的回归
  • 记号位置：力度记号与渐强/渐弱楔形线移到谱表下方且跨度完整；八度记号移出谱表、起止对齐； 速度记号的音符时值字形与文字对齐；Segno / Coda 画在小节开头，Fine / To Coda / D.C. / D.S. 画在小节末尾；渐强/渐弱方向不再写反；颤音 / 波音 / 回音与重音记号（^）固定在谱表上方
  • 字形错位：按官方 SMuFL 名表全量比对后修掉一批画错的记号（Segno / D.S. / D.C. 画成了别的记号、 速度记号的音符时值、踏板释放记号、跳音与保持音图标互换、琶音波浪线、低音谱号的 15mb / 8va 等）
  • 波音与装饰音：按参照渲染定案字形（<mordent> 带竖线、<inverted-mordent> 不带竖线）， 详情面板的中文标签与字形、说明一致；颤音 / 回音 / 逆回音 / 上·下波音的术语统一
  • 记谱修正：多声部小节里某个声部时值不足拍号时，补出的休止符不再丢附点；导入的 MusicXML 若没有时值标记，按实际时值推定（播放判断更准）；每个声部都填满本小节（不再「总时长对不上拍号」）； 末小节那条「很长的黑线」查清是多小节休止的横杠画得不成形，已改为规范画法
  • MusicXML：导出文件不再有格式违规（86 处清零，按官方 XSD 逐份校验）；新增罗马数字和弦与转位 （<function>，含上/下标数字）的解析、显示与导出；补齐隐藏音符（print-object="no"）、 <other-dynamics>、连音比率的 <normal-type>、开弦记号等写法；跨小节渐强不再丢失终点； 语料里纳入一份制谱软件 4.x 导出的乐谱，专门验证新版语法
  • 练习：新增音程训练 / 节奏型训练 / 和弦进行 / 视唱四类练习；短琶音按八度与方向展开， 改用考级通用的转位滑窗音型（原位 → 第一转位 → 第二转位 …），与长琶音区分开
  • 反复练习谱：「反复谱」重做为四份单一主题短谱（反复与结尾 / 小节·拍重复 / D.S.·Coda / D.C.·Fine）， 并修掉 To Coda 首遍误跳
  • 示例谱：随包《示例进行曲》补上跳音、重音、保持音、连音线、同音连线、波音、三连音、渐强与延长记号， 打开就能在「音符详情 → 音乐课堂」里逐条看到讲解
  • 简谱：新增简谱视图（实验）
  • 乐谱库：打开过的乐谱自动入库，可收藏、重命名、删除；新增曲目难度评级（纯本地分析）
  • 设置页：新增翻页方式（滑动 / 蓝牙踏板·键盘 / 半页）、Pencil 标注层、蓝牙 MIDI 输出、 链接与致谢；「关于」里可直接查到版号与 build 号
  • 快捷指令：支持用快捷指令 / Siri 打开最近乐谱（英文机上不再显示中文）
  • 改谱更安全：转调、连谱号等改动加二次确认
  • 体积与性能：音色库改为压缩 .sf3（约 13.9 MB，首次启动在本地解码），随包体积大幅下降； 播放设置不再触发全谱重排，音乐会音高与钢琴卷帘加上缓存，光标跟随更省电
  • 术语与文案：按通行制谱术语统一（「和弦记号」等）；「覆盖谱」取代旧称；补齐英文文案
  • 简谱、覆盖谱标注为实验功能

1.0（生产版本 · build 8）

  • 打开即看即听：MusicXML（.xml / .musicxml / .mxl）与制谱软件导出的矢量 PDF
  • Bravura 制谱排版：符头、符干、符杠、连音线、装饰音、和弦记号、反复记号与多声部休止符
  • 随包 GM 音色库离线播放：力度、踏板、跳音、延长记号、颤音 / 回音 / 波音与倚音按要求演奏
  • 走带：倒回起点、播放 / 暂停 / 继续、先点音符再播放即从该处起播
  • 音符详情与「音乐课堂」：音高、时值、声部与谱表、演奏法、力度、歌词与和弦记号
  • 反复与跳转：反复小节线、结尾（volta）、D.C. / D.S. al Fine、To Coda
  • 练琴：C / F / G 各调（含关系小调）的音阶、琶音与和弦练习，另有节拍器、变速、循环、摇摆与钢琴卷帘
  • 导出 PDF / PNG / MIDI / WAV / MusicXML；中英双语；完全离线、无账号、无广告、无内购
