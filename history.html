版本历史

1.1（开发中）

  • 播放：修掉「暂停后按继续又从头开始」；换谱后「继续播放」不再接着放旧谱；同一时刻只有一个播放实例
  • 排版：符杠不再压符头；连谱组按 2 个八度跨度上限断开（"符干交叉"消失）；换拍号处按实测字形宽留位； 修掉一批字形错位（Segno / D.S. / D.C. 画成别的记号、速度记号的音符时值画错、踏板释放记号、 跳音与保持音图标互换、琶音波浪线、低音谱号的 15mb/8va）
  • 波音：按参照谱的渲染对照确定字形（<mordent> 带竖线、<inverted-mordent> 不带竖线）， 详情面板的中文标签与字形、说明一致
  • MusicXML：新增罗马数字和弦与转位（<function>，含上/下标数字）的解析、显示与导出； 导出文件不再有格式违规；补齐隐藏音符（print-object="no"）、<other-dynamics>、 连音比率的 <normal-type>、开弦记号等写法；跨小节渐强不再丢失终点
  • 示例谱：随包《示例进行曲》补上跳音、重音、保持音、连音线、同音连线、波音、三连音、渐强与延长记号， 打开就能在「音符详情 → 音乐课堂」里逐条看到讲解
  • 练习：「反复谱」重做为四份单一主题的短谱（反复与结尾 / 小节·拍重复 / D.S.·Coda / D.C.·Fine）
  • 术语与文案：按通行制谱术语统一（「和弦记号」等）；「覆盖谱」取代旧称；快捷指令文案补英文
  • 安装包：音色库改为压缩 .sf3（首次启动在本地解码），下载体积从约 134 MB 降到约 13 MB
  • 简谱、覆盖谱标注为实验功能
  • 要求 iOS 16.0+，支持 iPhone / iPad

1.0（当前发布版本）

  • 打开即看即听：MusicXML（.xml / .musicxml / .mxl）与制谱软件导出的矢量 PDF
  • Bravura 制谱排版：符头、符干、符杠、连音线、装饰音、和弦记号、反复记号与多声部休止符
  • 随包 GM 音色库离线播放：力度、踏板、跳音、延长记号、颤音 / 回音 / 波音与倚音按要求演奏
  • 走带：倒回起点、播放 / 暂停 / 继续、先点音符再播放即从该处起播
  • 音符详情与「音乐课堂」：音高、时值、声部与谱表、演奏法、力度、歌词与和弦记号
  • 反复与跳转：反复小节线、结尾（volta）、D.C. / D.S. al Fine、To Coda
  • 练琴：C / F / G 各调（含关系小调）的音阶、琶音与和弦练习，另有节拍器、变速、循环、摇摆与钢琴卷帘
  • 导出 PDF / PNG / MIDI / WAV / MusicXML；中英双语；完全离线、无账号、无广告、无内购
