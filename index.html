功能

  • 打开乐谱：MusicXML 三种格式都支持 —— .xml、.musicxml 与压缩包 .mxl；也能直接读取制谱软件导出的矢量 PDF（实验性）
  • 专业排版：Bravura 制谱字体，符头、符干、符杠、连音线、装饰音、和弦符号、反复记号与多声部休止符都按制谱规范绘制
  • 开箱即有声：内置 GM 音色库，无需下载；力度、踏板、跳音、延长记号、颤音 / 回音 / 波音与倚音都会按要求演奏
  • 走带顺手：倒回到起点、播放 / 暂停 / 继续（暂停后从停下的位置接着放）；先点一个音符再播放，就从该小节起播
  • 音符详情：点选任意音符查看音高、时值、声部与谱表、所在小节与拍位、演奏法与力度、歌词与和弦符号
  • 反复与跳转：反复小节线、结尾（volta）、D.C. / D.S. al Fine、To Coda 都按谱面走；播放光标沿记谱位置推进，休止符与同音连线同样正确
  • 练习：任意调性的音阶（上下行、1–3 个八度、可带终止式 —— 终止式与回主音的连线按考级教材写法），另有节拍器、变速、循环、摇摆与钢琴卷帘
  • 两份内置范例：G 大调（3 个八度）与 a 和声小调（2 个八度），含终止式，以原始 MusicXML 文件随包分发
  • 导出：PDF / PNG / MIDI / WAV / MusicXML，统一经系统分享面板保存或发送
  • 中英文界面，完全离线

支持

常见问题：

  • 导入 PDF 后时值不准？ 矢量 PDF 直读是实验性功能：谱表、音高与小节能准确还原，时值仍为近似值，导入后请核对。
  • 能编辑乐谱吗？ 本应用是只读的：用于看谱、听谱与练习，不提供改谱功能（详情面板里的是演奏设置：乐器音色、静音、混音、转调）。
  • 没有声音？ 播放使用应用内置的音色库（随包分发，无需下载）；若仍无声，请检查设备音量与静音开关。
  • 支持哪些格式？ MusicXML（.xml / .musicxml）、压缩 MusicXML（.mxl）与矢量 PDF。本版本不含图像识别（OMR），也不支持 MIDI 导入。
